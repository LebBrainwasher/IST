HORUS Mobile — Guide rapide

Surveillance tactique • fonctions essentielles

1 — Saisir un événement

  • Choisissez START, STOP, OBS, CONT ou DIR, puis saisissez ou dictez l’observation.
  • OBS — Observation est le type courant pour la prise de notes.
  • La ligne validée est horodatée automatiquement.

2 — Géolocalisation

  • Appuyez sur 📍 Position avant de valider une ligne pour lui associer le point GPS de l’opérateur.
  • Un point déjà associé peut être consulté depuis la ligne ; les coordonnées peuvent être ouvertes volontairement dans un service cartographique.

3 — Clichés photographiques

  • Appuyez sur 📷 Photo pour prendre ou sélectionner un cliché avant la validation de l’événement.
  • Plusieurs médias peuvent être liés à une même ligne et consultés ensuite dans le visualiseur.

4 — Corriger une ligne

  • Touchez une ligne déjà créée pour modifier son type d’action ou son commentaire.
  • Depuis cette même fenêtre, une ligne peut être supprimée après confirmation.

5 — Sauvegarder, rouvrir et PDF

  • Exporter conserve la surveillance pour une reprise ou un transfert ultérieur ; avec des clichés, HORUS peut produire une archive contenant les médias.
  • Importer permet de rouvrir une surveillance tactique exportée précédemment.
  • PDF génère le rapport avec le choix sans média ou avec médias lorsque des photographies sont disponibles.

6 — Poursuivre l’exploitation

Une ou plusieurs surveillances HORUS peuvent ensuite être chargées dans HORUS Analyseur de récurrences afin de croiser les événements, véhicules, individus, lieux, contacts, médias et positions relevés.

HORUS Mobile — Dictée rapide

Mots-clés, immatriculations et validation vocale

Commandes de début de phrase

START / DÉPARTSélectionne START.
STOP / ARRÊTSélectionne STOP.
OBS / OBSERVATION(S)Sélectionne Observation.
CONT / CONTACTSélectionne Contact.
DIR / DIRECTIONSélectionne Changement de direction.
CHGT DIRECTIONVariante longue de DIR.

Commande en cours de phrase

IMMATRICULATION : annonce qu’une plaque va être dictée. HORUS interprète les lettres phonétiques et normalise une plaque reconnue, par exemple « Papa Mike 628 November Victor » → PM-628-NV.

Validation vocale

Terminez la phrase par VALIDER, VALIDÉ ou VALIDE pour déclencher la même action que le bouton OK. Le mot de commande n’est pas conservé dans le commentaire.
